# Feature Specification: 用户资料编辑

**Feature Branch**: `002-edit-user-profile`

**Created**: 2026-09-02

**Status**: Draft

**Input**: User description: "实现一个用户资料编辑功能"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 编辑并保存个人资料 (Priority: P1)

已登录用户进入个人资料编辑页面，修改昵称、个人简介、性别和生日等基础资料，保存后立即看到最新资料，并在之后重新进入时仍能看到已保存内容。

**Why this priority**: 修改并持久保存资料是本功能的核心价值；只实现这一流程即可交付可用的最小版本。

**Independent Test**: 使用已有账号登录，进入资料编辑页面，修改一个或多个字段并保存；离开页面后重新进入，确认展示内容与最后一次保存一致。

**Acceptance Scenarios**:

1. **Given** 用户已登录且拥有现有个人资料，**When** 用户进入资料编辑页面，**Then** 页面展示当前已保存的资料，并明确区分可编辑与不可编辑字段。
2. **Given** 用户修改了一个或多个可编辑字段且内容合法，**When** 用户点击保存，**Then** 系统保存全部有效变更、提示保存成功，并展示最新资料。
3. **Given** 用户未修改任何字段，**When** 用户查看编辑页面，**Then** 系统不提示存在待保存变更，也不会产生无意义的资料更新。
4. **Given** 用户已成功保存资料，**When** 用户离开后重新进入个人资料页面，**Then** 系统展示最后一次成功保存的内容。

---

### User Story 2 - 更换个人头像 (Priority: P2)

已登录用户可以选择新的头像图片，在确认前预览效果，并在图片符合要求时保存为新头像。

**Why this priority**: 头像是用户身份展示的重要组成部分，但不影响基础资料编辑流程独立交付。

**Independent Test**: 选择一张符合要求的图片，检查预览后保存；刷新页面并在用户资料展示位置确认头像已更新。

**Acceptance Scenarios**:

1. **Given** 用户在资料编辑页面，**When** 用户选择符合格式和大小要求的图片，**Then** 页面在保存前展示新头像预览。
2. **Given** 用户已预览新头像，**When** 用户确认保存，**Then** 系统更新头像并在所有用户自己的资料展示位置显示新头像。
3. **Given** 用户选择的文件格式不受支持、文件损坏或超过大小限制，**When** 系统校验文件，**Then** 系统拒绝该文件、保留原头像并说明原因。

---

### User Story 3 - 安全处理无效输入与未保存变更 (Priority: P3)

用户在填写不符合要求的资料、保存遇到异常或带着未保存变更离开页面时，能够得到明确提示，不会误以为资料已保存或意外丢失输入。

**Why this priority**: 完整的错误与离开保护可降低资料填写失败和意外丢失带来的困惑，是核心流程后的体验保障。

**Independent Test**: 分别输入过长昵称、超长简介，模拟保存失败，并在有未保存变更时离开页面；验证系统阻止无效提交、保留用户输入并给出准确提示。

**Acceptance Scenarios**:

1. **Given** 用户输入的字段不符合规则，**When** 用户尝试保存，**Then** 系统定位到对应字段并显示可操作的错误说明，不保存任何无效变更。
2. **Given** 用户提交了合法资料但保存失败，**When** 系统返回失败结果，**Then** 页面保留用户输入、明确提示未保存成功，并允许用户重试。
3. **Given** 用户存在未保存变更，**When** 用户尝试离开或关闭编辑页面，**Then** 系统提醒用户变更尚未保存，并允许其继续编辑或确认放弃。
4. **Given** 用户登录状态已失效，**When** 用户尝试保存资料，**Then** 系统不保存变更，提示重新登录，并避免将未授权内容写入账户。

### Edge Cases

- 用户在多个页面或设备上同时编辑同一份资料时，后提交的一方不得在无提示的情况下覆盖其打开页面后已被其他会话更新的内容。
- 用户只输入空格、换行或不可见字符时，系统按去除首尾空白后的内容进行必填及长度校验。
- 头像上传过程中网络中断或用户取消操作时，原头像保持不变，且不会显示未完成的头像。
- 用户保存时网络暂时不可用，页面保留全部输入并提供重试入口，不重复创建或叠加相同变更。
- 用户输入表情、多语言字符或常用标点时，只要满足字段长度与内容规则，系统能够正确保存并再次展示。
- 用户资料中已有历史数据不符合当前规则时，页面可以展示原值；用户修改对应字段后必须满足当前规则才能保存。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 系统 MUST 仅允许已登录用户查看和编辑其本人资料。
- **FR-002**: 系统 MUST 在编辑页面展示当前已保存的用户资料，并明确标识可编辑字段和不可在本功能中修改的账户字段。
- **FR-003**: 用户 MUST 能够编辑昵称、个人简介、性别和生日；除昵称外，其余字段允许留空。
- **FR-004**: 系统 MUST 将昵称去除首尾空白后校验为 2 至 30 个可见字符，并拒绝仅由空白或不可见字符组成的昵称。
- **FR-005**: 系统 MUST 将个人简介限制在 200 个字符以内，并向用户展示清晰的长度限制或剩余可输入字符数。
- **FR-006**: 系统 MUST 拒绝晚于当前日期的生日；用户可以清除已填写的生日和性别。
- **FR-007**: 用户 MUST 能够选择头像图片并在提交前预览；系统仅接受常见图片格式，单个文件不得超过 5 MB。
- **FR-008**: 系统 MUST 在头像文件不受支持、损坏或超过大小限制时拒绝更新，保留原头像并说明失败原因。
- **FR-009**: 系统 MUST 对所有字段完成校验后再保存，并保证一次提交中的资料变更要么全部成功，要么全部不生效。
- **FR-010**: 系统 MUST 在保存成功后向用户提供明确反馈，并在后续访问中展示最后一次成功保存的资料。
- **FR-011**: 系统 MUST 在保存失败时保留用户尚未保存的输入，说明失败状态并允许重试。
- **FR-012**: 系统 MUST 在用户带着未保存变更离开编辑页面前发出提醒，并允许用户取消离开或确认放弃变更。
- **FR-013**: 系统 MUST 防止过期页面无提示覆盖已被其他会话更新的资料；发生冲突时应提示用户重新加载最新资料后再决定如何修改。
- **FR-014**: 系统 MUST 支持昵称和个人简介中的多语言文字、表情及常用标点，并在保存后保持内容一致。
- **FR-015**: 系统 MUST 使资料编辑流程符合键盘操作、可见焦点、语义化错误提示和辅助技术读取要求。
- **FR-016**: 系统 MUST 在用户登录状态失效时拒绝保存，并引导用户重新登录。

### Key Entities *(include if feature involves data)*

- **用户资料 (User Profile)**: 用户面向自己及产品内其他展示场景的基础身份资料；包含用户唯一标识、昵称、个人简介、性别、生日、头像以及资料最后更新时间。
- **头像 (Profile Image)**: 与用户资料关联的展示图片；包含图片标识、可访问位置、格式、大小以及当前生效状态。
- **资料变更 (Profile Change)**: 用户一次保存操作中提交的字段集合；用于区分当前已保存资料、页面内待保存内容及潜在的并发修改冲突。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 至少 95% 的目标用户能够在首次尝试中于 2 分钟内完成一项资料修改并确认保存结果。
- **SC-002**: 对合法资料的保存操作，95% 的用户在点击保存后 2 秒内看到明确的成功或失败结果。
- **SC-003**: 对超长、空白昵称、未来生日和不合规头像等预定义无效输入，拦截率达到 100%，且每次均在对应位置提供明确原因。
- **SC-004**: 保存失败、并发冲突或用户取消离开时，用户已输入但未主动放弃的文本内容保留率达到 100%。
- **SC-005**: 在键盘操作与屏幕阅读器验收中，核心编辑、校验、保存及错误恢复流程的任务完成率达到 100%，并满足 WCAG 2.1 AA 要求。
- **SC-006**: 用户资料成功保存后，在所有用户自己的资料展示位置中，最新昵称和头像的一致展示率达到 100%。

## Assumptions

- 本功能面向已经注册并登录的普通用户；管理员代替用户修改资料不在本次范围内。
- 昵称、个人简介、性别、生日和头像属于可编辑资料；手机号、邮箱、密码、账号绑定和实名认证信息属于账户安全或身份验证流程，不在本次范围内。
- 性别为可选资料，用户可以选择产品当前支持的选项或不公开；具体展示文案沿用产品既有规范。
- 头像支持产品当前接受的常见图片格式，默认最大 5 MB；裁剪、滤镜及图片美化不属于本次范围。
- 用户资料的对外可见范围沿用现有隐私设置；本功能不新增隐私权限配置。
- 产品已有登录态、用户资料读取和通用消息提示能力，本功能在此基础上扩展资料编辑体验。
